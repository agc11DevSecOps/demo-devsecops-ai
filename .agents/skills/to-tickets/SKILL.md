# To Tickets

Break approved work into vertical slices. Every slice must be independently demonstrable and declare only its genuine blockers. Use the configured local tracker at `issues/`.

For each ticket include a short title, blockers, user-visible delivery and acceptance criteria. Do not publish to a remote tracker, modify parent issues, or perform network operations.
